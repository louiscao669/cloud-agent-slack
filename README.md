# cloud-agent-slack

## Data files

- `data/cefr-words.json` - full English Words CEFR Dataset from
  [`Maximax67/Words-CEFR-Dataset`](https://github.com/Maximax67/Words-CEFR-Dataset),
  converted from the upstream CSV tables into a single JSON file. It includes
  248,184 word/POS CEFR records from A1-C2, plus POS tags, category metadata,
  source attribution, and MIT license metadata.
